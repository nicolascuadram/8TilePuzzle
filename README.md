# 8 Tile Puzzle with Breadth-First and Depth-First searches for AI course.

## Developer

- Nicolás Cuadra

## Requiremets

- Java 8 or higher
- Java compiler (Javac)

## Compilation

To compile the proyect, you must navegate to the directory with `Main.java` file and execute the next command in the console:

```bash
javac Main.java
```

## Execution

To execute the program, use the next command in the console:

```bash
java Main <algorithm>
```

Where:

`<algorithm>` it's an argument to represent which algorithm will be used in the execution, 1 for BFS, 2 for DFS, and 3 for both algorithms.

For example, an execution for both algorithms will be:

```bash
java Main 3
```
